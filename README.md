# Помощник по заказ-нарядам Tesla

Консольный AI-помощник мастера-приёмщика: в свободной форме описываете клиента, автомобиль и
проблему — помощник (Claude) расшифровывает VIN, подбирает работы и запчасти из справочника
сервиса, считает итог с НДС и сохраняет заказ-наряд в JSON и HTML для печати.

Пример печатной формы: [`examples/zakaz-naryad-primer.html`](examples/zakaz-naryad-primer.html).

## Установка и запуск

```bash
pip install -e ".[dev]"
export ANTHROPIC_API_KEY=sk-ant-...
python -m tesla_ro.web        # или: tesla-ro-web
```

Откройте в браузере http://127.0.0.1:8000.

![Веб-интерфейс](docs/web.png)

- **Слева — чат с помощником.** Пишите в свободной форме, можно всё сразу:
  «Петров Пётр, +7 900 123-45-67, VIN 7SAYGDEEXPF000001, пробег 62300, скрипит спереди при
  торможении». Под полем ввода есть быстрые подсказки.
- **Справа — заказ-наряд**, обновляется после каждого ответа: клиент, автомобиль, жалобы,
  работы, запчасти, итог с НДС и список незаполненных обязательных полей.
- **🖨 Печать** открывает печатную форму (из браузера можно сохранить в PDF).
- **📁 Сохранённые** — список заказ-нарядов: открыть для правки или распечатать.
- **＋ Новый** — начать новый заказ-наряд.
- На телефоне чат и заказ-наряд переключаются вкладками.

Чтобы открыть сервис для других компьютеров в сети: `--host 0.0.0.0 --port 8000`.
Авторизации нет — не выставляйте сервис в интернет без защиты (VPN или прокси с паролем).
Диалоги хранятся в памяти сервера и пропадают при перезапуске; сохранённые заказ-наряды
лежат в `orders/` (JSON).

Остальные параметры: `--catalog путь.json` (свой справочник), `--orders-dir папка`,
`--model`, `--effort low|medium|high|xhigh|max`.

Консольная версия: `python -m tesla_ro`.

## Что умеет

- **VIN Tesla**: модель (S/3/X/Y/Cybertruck), модельный год, завод, проверка контрольной цифры
  для североамериканских VIN (`tesla_ro/vin.py`).
- **Справочник** работ (код, нормо-часы, применимость к моделям, типовые запчасти) и запчастей
  с ценами — `tesla_ro/data/catalog.json`. Там же реквизиты сервиса, ставка нормо-часа, валюта
  и НДС (по умолчанию 22 %, цены с НДС).
- **Заказ-наряд**: клиент, автомобиль, жалобы, диагностика, работы, запчасти, скидки,
  рекомендации; автонумерация `ЗН-<год>-<номер>`; нельзя закрыть без обязательных полей.
- Нестандартные работы и запчасти — по цене, которую называет мастер (модель цены не выдумывает).

## Настройка под свой сервис

Отредактируйте `tesla_ro/data/catalog.json` (или передайте свой файл через `--catalog`):
реквизиты, `labor_rate_per_hour`, `vat_percent`, `prices_include_vat`, списки `operations`
и `parts`. **Цены и нормо-часы в комплекте — условные примеры**, замените их своими.

## Устройство

| Файл | Назначение |
|---|---|
| `tesla_ro/web.py`, `tesla_ro/static/index.html` | Веб-сервер (FastAPI) и страница интерфейса |
| `tesla_ro/assistant.py` | Агент на Claude API (tool runner, адаптивное мышление, fallback при отказе) |
| `tesla_ro/tools.py` | Инструменты агента — операции над заказ-нарядом |
| `tesla_ro/order.py` | Модель заказ-наряда, расчёт итогов, хранение в JSON |
| `tesla_ro/render.py` | HTML-форма для печати |
| `tesla_ro/catalog.py`, `tesla_ro/vin.py` | Справочник и декодер VIN |

Тесты (без обращения к API): `pytest`.
